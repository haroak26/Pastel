# Figma Reference — Adaptive Fitness Coach Home

This reference is a coaching dashboard, not a marketplace, catalog, or social
feed. The page tells one story: understand today's plan, then start it.

## Composition

- Use a quiet white canvas with a compact top heading and notification control.
- The main content is a two-column desktop composition: a wider training column
  and a narrower coaching/action column.
- The dominant moment is a pale blue session panel, not a photo gallery or
  search bar.
- Place the coach insight beside the session panel. Put the primary action in
  the action column, not in multiple competing locations.
- Follow the hero with small category pills, then a clearly titled exercise
  sequence made from outlined rows.
- Finish with a soft gray after-workout band containing two compact recovery
  cards.

## Surfaces and spacing

- Use restrained rounded corners, hairline borders, and very soft tonal fills.
- Cards are functional containers, not decorative floating panels.
- Keep the blue accent concentrated in the session action, numbered exercise
  state, links, and primary button.
- Use generous but intentional whitespace. Do not create an empty hero region.
- Exercise rows are information-dense but calm: number, title, sets/reps,
  coaching cue, and a quiet Swap action.

## Type and content

- Use a strong black page headline, medium-weight section titles, and muted gray
  metadata.
- Keep labels small and quiet; values are readable without oversized display
  typography.
- Content must be specific to strength coaching: duration, intensity, target,
  readiness, sets, reps, load, form cues, recovery, and soreness.
- Never introduce Where, dates, guests, host, nightly price, reviews, or
  availability language.

## Review standard

Reject output that reads like Airbnb, a generic SaaS dashboard, a repetitive
catalog grid, or a marketing landing page even if its geometry passes. Judge the
relationship between the session hero, coach insight, action column, sequence
rows, and recovery band as one authored composition.
