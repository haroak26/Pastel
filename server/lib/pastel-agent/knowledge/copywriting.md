# Copywriting Standards

All copy in a Pastel design is real, specific, and finished. The design should read like a shipped product, not a wireframe.

## Rules

1. **Specific over generic.** "Batch-export brand assets in one click" — never "Powerful features for your workflow".
2. **Concrete numbers when plausible.** "4,200 teams" is fine if the brief implies scale; otherwise avoid invented metrics. Never "Trusted by thousands".
3. **Buttons describe the action.** "Create project", "See pricing", "Browse the collection" — never "Submit", "Click here", "Learn more" without context.
4. **Headlines say one real thing.** A headline makes a claim or names a value. It is never a buzzword stack.
5. **Banned vocabulary:** modern, seamless, innovative, cutting-edge, next-generation, revolutionary, empower, unlock, supercharge, elevate, streamline (unless the user's own prompt uses them — user vocabulary always wins).
6. **Tone follows the brief.** A children's charity and a quant trading firm do not sound alike. Match register, vocabulary, and sentence length to the audience in the brief.
7. **Microcopy matters.** Form placeholders, empty states, footer text, and nav labels are all written, all specific.
8. **Length discipline.** Headlines ≤ 8 words. Section intros ≤ 25 words. Body paragraphs ≤ 40 words. UI labels 1–3 words.
9. **No emoji** anywhere in UI copy.
10. **Product names** come from the brief. If the user gave no name, invent a short, plausible one and use it consistently across every screen.
